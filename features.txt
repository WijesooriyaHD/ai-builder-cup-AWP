* Strength Training
* Recovery & Relaxation
* Meditation
* Breathing Exercises
* Mindful Movement

Selection Rules

The user must select at least 3 methods.

There is NO maximum selection limit.

Users can select:

* 3 methods
* 4 methods
* 5 methods
* 6 methods
* Or more

Do not restrict users to exactly 3.

The Continue button must remain disabled until at least 3 methods are selected.

Display the number selected, for example:

“3 methods selected”

or:

“6 methods selected”

If fewer than 3 are selected, show:

“Select at least 3 wellness methods.”

If the user selects more than 3, there should be no warning or error.

Users should be able to freely select and deselect methods.

However, prevent the user from saving/continuing if the final selection contains fewer than 3 methods.

Use:

* Clear selected/unselected states
* Smooth selection animations
* Accessible touch targets
* Light Mode
* Dark Mode
* Existing AI Wellness Pal typography, spacing, cards, and visual language

5. Preferred Wellness Methods — AI Behavior

Preferred Wellness Methods should become a strong personalization signal.

However, selecting many methods does NOT mean the AI must use every method in one day’s plan.

For example, a user may select:

* Pilates
* Yoga
* Walking
* Stretching
* Mobility
* Meditation
* Breathing

Gemini should treat these as the user’s preferred wellness toolkit.

For each individual day, select the most appropriate method(s) based on:

1. Daily Check-in
2. Energy
3. Mood
4. Recovery
5. Available time
6. Wellness Intentions
7. Recent Plan History
8. Preferred Wellness Methods
9. Premium Life Toolkit data, if applicable

The AI should maintain variety across the user’s preferred methods.

Do not repeatedly generate the same method if other preferred methods are suitable.

Nutrition

* Energy-supporting recommendations
* Recovery
* Wellness-related actions

Do not force nutrition data into every plan.

Hydration

If hydration is behind target, the plan may include:

* Hydration reminder
* Water break
* Light movement + hydration break

Sleep

If recent sleep data indicates poor sleep:

Prefer:

* Gentle Pilates
* Restorative Yoga
* Mobility
* Stretching
* Breathing
* Recovery

and reduce unnecessary intensity.

If sleep is good, normal activity can be considered alongside check-in data.

Activity

Use recent activity to:

* Avoid unnecessary repetition
* Avoid excessive movement
* Balance the user’s recent activity

Meditation / Mindfulness

Relevant mindfulness data can influence:

* Meditation
* Breathing
* Stress relief
* Mindful movement

Habit Builder

Use relevant habit progress to reinforce active habits.

Example:

If the user has an active hydration challenge, Today’s Plan may include a hydration action.

Sleep Coach

Use relevant sleep information to adjust intensity and recovery recommendations.

Other Life Toolkit Features

Use data from the remaining Life Toolkit features only when it provides meaningful personalization.

Do NOT force every tool into every Today’s Plan.
